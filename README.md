# Sigma Spore Plague (Forge 1.16.5)

Грибной апокалипсис в духе Parasites.

## Что есть
- Заражение: удар Грибного зомби / стояние на заражённых блоках / близость к заражённому (стадия 2+) -> эффект «Заражение спорами» (5 минут).
- 4 стадии: голод -> слабость и замедление (заразен для окружающих) -> тошнота, слепота, урон.
- Когда таймер кончается (или заражённый умирает) он превращается в Грибного зомби: игрок, житель, свинья, кто угодно. Игрок оставляет зомби со своим ником.
- Заражённая масса и Ядро грибницы расползаются по миру (случайные тики). Ядро светится и рожает зомби.
- Сыворотка (стекл. бутылка + золотое яблоко + ферм. паучий глаз, или 5% дроп с зомби): снимает инфекцию + 5 минут иммунитета.
- Гейм-правило `/gamerule sigmaSporeSpread false` выключает расползание блоков.
- Креатив и спектатор не заражаются.

## Сборка
1. Скачай Forge MDK 1.16.5 (36.2.x) с files.minecraftforge.net, возьми оттуда gradlew, gradlew.bat и папку gradle/.
2. Положи их в эту папку рядом с build.gradle.
3. JDK 8:  `./gradlew genIntellijRuns` (или genEclipseRuns), потом `./gradlew runClient`
4. Сборка jar: `./gradlew build` -> build/libs/

## Получить .jar без установки Forge (GitHub Actions)
1. Создай репозиторий на github.com и загрузи в него все файлы этой папки (включая скрытую `.github`).
2. Вкладка Actions -> Build mod jar -> дождись зелёной галочки (3-5 минут).
3. Открой запуск и внизу в Artifacts скачай `sigmaspores-jar`. Внутри будет `sigmaspores-1.16.5-1.0.0.jar`.
4. Положи jar в `.minecraft/mods` при установленном Forge 1.16.5 (36.2.x).
